# PIKKO

App web de retos semanales para crear hábitos sanos: deporte, cocina, aprender una skill, cultivar un hobby o desconectar. Engancha como una red social, pero para promover cosas positivas.

Proyecto Intermodular · CFGS Desarrollo de Aplicaciones Web · 2026-2027

## Tecnologías

| Parte | Tecnología |
|---|---|
| Backend | Java + Spring Boot (Spring Web, Spring Data JPA, Spring Security con JWT) |
| Frontend | React + Vite |
| Base de datos | PostgreSQL |
| Verificación de fotos | Google Cloud Vision (Incremento 2) |
| Pruebas | JUnit + Mockito |
| Integración continua | GitHub Actions |
| Entorno | Docker Compose |

## Estructura

```
backend/    API REST con Spring Boot
frontend/   Aplicación React
database/   Scripts SQL (datos iniciales de retos)
docs/       Memorias de cada sprint y capturas
```

## Entregas

- **Incremento 1** (9 de diciembre de 2026): registro, login, ver retos y completar retos autodeclarados.
- **Incremento 2**: retos con foto verificada automaticamente y panel de administración.
- **Incremento 3**: mejoras de usabilidad y funciones avanzadas.
- **Entrega final**: versión completa y documentada para la defensa.
